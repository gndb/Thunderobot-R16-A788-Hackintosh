# WebKit图形库可执行映射被拒

状态：11月14日15:49的0.8.2会话仍有相关用户态拒绝记录，根因未定。

相关摘要显示WebKit.GPU对Intel和NVIDIA两类Metal插件的可执行映射被拒。同会话Intel CLI小型计算成功，这两件事可以同时发生；CLI成功不代表所有沙盒应用能加载系统侧插件。

需要补充一致的触发操作、受影响应用/服务、库版本和签名状态、同一启动的相关拒绝片段及配置条件。公开时保留库相对名称、错误类别和时间关系，清理用户环境与无关进程。

当前不将它直接归责核显、NVIDIA或某个CPU特性，也不把进一步放宽安全策略当作已验证修复。BetterDisplay UD2是[另一份应用崩溃专题](betterdisplay.md)，不能因同期发生就合并根因。
