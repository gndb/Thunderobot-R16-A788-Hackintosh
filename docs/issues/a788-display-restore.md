# A788显示接管与恢复

平台：R16／NLYA／TP181，i9-13900HX、A788 rev04、BOE NE160QDM-NZL。当前高刷关闭。

## 已观察

- 启动曾出现有背光无图像，但键盘有系统响应。加速器probe／start返回成功仍不等于可见首帧完成。
- 曾在等待或可能显示唤醒后恢复画面，缺可靠同步记录，尚未确认具体触发动作。
- 11月14日15:49出现正常桌面、60Hz和小型Intel计算成功；重复冷启动及熄屏恢复未完整验收。
- 放置后变暗、点击无法恢复曾复现，之后强制关机。显示熄屏与整机睡眠需分别定位。

## 下次复现记录

同一启动按顺序记录OpenCore交接、内核probe、加速器start、WindowServer、首次图像、显示熄屏／唤醒及整机睡眠。保留配置与二进制指纹、显示路由、冷启动或重启方式、操作与等待时间，以及最短相关日志。

公开会话身份用一致的`BOOT_A／BOOT_B`代换。已有键盘响应只说明系统可能在运行，不再用它重复验证显示管线。

## 修复范围

上游已有[保留固件布线并延后激活](https://github.com/b00t0x/WhateverXe/commit/37580ea572c8858c3a584aea9a58e9c60f102ca9)机制。本机可贡献门禁、检查点和未覆盖案例；现有大补丁尚不能作为通用显示恢复修复。R10／R11及高刷实验未并入当前通过范围。
