# 功能状态与已知问题

更新：2026-11-16。当前根`EFI/`采用WEX0.8.2-R16、UTBMap1.0.3、AirportRTW2.3.3，高刷关闭。**最新USB／无线修订尚未完成同次启动的完整验收**；下列成功记录按实际会话归属保存。

## 哪些功能已有结果

| 功能 | 记录结果 | 已验证范围 |
|---|---|---|
| 内屏显示 | 11月14日15:49可见2560×1600／60 Hz桌面 | 单次成功会话；另有冷启动无图像记录 |
| 亮度 | 同次会话全范围连续调节有用户确认 | 熄屏／睡眠后恢复仍有问题 |
| Intel GPU | 同次会话1024元素整数计算回读0错 | 基础计算，不覆盖完整媒体和全部图形应用 |
| NVIDIA 3.0 | 同次会话NVRM／NVAccel／NVRMFramebuffer／NVRMAGDC四模块加载 | headless；新版双GPU七项作业待复测 |
| 键盘／触摸板 | 有基本功能可用记录 | 全按键、手势及恢复场景待测 |
| 音频／摄像头 | 有基本功能可用记录 | 全接口、全部应用及恢复场景待测 |
| 网络／USB-A | 有基本功能可用记录 | AirportRTW2.3.3、吞吐及全部USB口待完整复测 |
| 后置Type-C数据 | 11月15日Windows同口USB2／USB3.x正反插可枚举，确认HS04／SS02 | 当前图与采集器已同步；macOS新映射完整复测待补，供电另查 |

[11月14日成功回退版](../profiles/usable-20261114/)对应上述可见桌面会话。11月13日WEX0.8.0／NVIDIA2.7.2另有七项基础离屏作业通过记录，详见[版本历史](HISTORY.md)，不归入当前新版验收。

## 哪些问题尚未解决

| 优先级 | 问题 | 已观察与下一步 |
|---|---|---|
| 1 | Type-C供电 | Windows／macOS给手机充电均异常；电脑输入供电测试也未报告外接电源。分开核对输入、输出角色与EC／PD／保护状态，见[USB专题](issues/usb-typec.md) |
| 1 | 冷启动首次显示接管 | 系统有响应但内屏有背光无图像。按同一次启动追踪显卡、WindowServer和首帧，见[显示专题](issues/a788-display-restore.md) |
| 1 | 沙盒图形库加载 | WebKit.GPU映射Intel／NVIDIA插件被拒，需独立定位，见[应用专题](issues/applications.md) |
| 2 | 熄屏／睡眠恢复 | 曾变暗后无法点亮；显示熄屏与整机睡眠分别复现 |
| 2 | 媒体与合成器 | 私有媒体模型编译、完整硬编硬解、视频绿闪及WindowServer同步等待待定位 |
| 2 | BetterDisplay崩溃 | 5.2.1出现UD2，应用问题独立复现，见[应用专题](issues/applications.md) |
| 3 | 外屏与其他功能 | 外屏逐接口、OEM ACPI／遥测、长期负载及存储恢复未完整验收 |

## 当前版本如何使用

按[安装说明](INSTALL.md)及[包内容清单](PACKAGING.md)准备同一版本组合，保留成功回退入口。当前EFI适合继续测试本机修订；新用户应先确认可见桌面与基本功能，再逐项测问题场景。

240／300 Hz、DSC、HDR、VRR及R10／R11恢复试验未并入通过范围。CPUFriend保留EPP64配置意图，实际性能／续航收益未独立测量。不同版本、不同启动会话的结果分别记录，文件校验和离线测试不替代硬件验收。
